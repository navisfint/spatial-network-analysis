# 区域经济空间网络分析工具集

**从面板数据到网络指标，一条命令出结果。** 面向区域经济、共同富裕、新质生产力这类
"多指标 → 综合指数 → 空间关联网络"的实证研究，把文献里散落的公式落地成可复现的代码。

两个独立模块，一套代码：

| 模块 | 做什么 | 输出 |
|---|---|---|
| **障碍度模型** | 识别制约因素（传统障碍度）与驱动来源（改进驱动度） | 双榜排名 + Spearman 相关性 + 反转检验 |
| **空间网络分析** | 修正引力模型构建省际关联矩阵 → 社会网络指标 | 密度/中心度/CONCOR/核心-边缘 + 网络图 |

**核心特点：不是"照着公式写一遍"，而是拿已发表论文的公开数值反查实现。**
10 项指标逐位对上（含网络密度、点度/接近中心度、网络效率），3 项对不上的已定位原因。

技术栈：`numpy` / `pandas` / `scipy` / `networkx` / `matplotlib` / `openpyxl`

> **先看哪份？**
> - 想知道「改进障碍度到底改了什么、为什么两个前5不同」→ **`说明_01_障碍度模型_改进vs传统.md`**
> - 想知道「修正引力模型 + 社会网络分析怎么做」→ **`说明_02_社会网络分析_含修正引力模型.md`**

## 项目 1：传统障碍度 vs 改进障碍度

| | 传统障碍度 | 改进驱动度 |
|---|---|---|
| 公式 | `(1−X)·f / Σ(1−X)·f` | `X·f / Σ X·f` |
| 分解对象 | 缺口（离理想值的距离） | 得分（当前水平） |
| 高值含义 | 短板、制约因素 | 长板、贡献来源 |

**核心结论：两者唯一区别是分子里的 `X` 换成了 `1−X`。**
→ 它们在问相反的问题，**前5不同是设计如此**。
→ 但两榜差异有多大，取决于你的数据里「权重离散度」和「水平离散度」谁更大，
   **不是固定规律**。代码会输出 Spearman 相关 + 交集数帮你判断。

```bash
python obstacle_model.py --data ../data/你的数据.xlsx --weight cv --std max --top 10
```
→ 先看 `5_反转检验` sheet，再看 `1_指标明细与两模型排名`。

## 项目 2：修正引力模型 + 社会网络分析

两种引力模型口径都实现了：

| 版本 | 公式 | 出处 |
|---|---|---|
| A 地理距离 | `P_ij = G_i/(G_i+G_j) · G_iG_j / D_ij²` | 魏巍(2025) 统计与决策 |
| B 经济地理距离 | `R_ij = V_i/(V_i+V_j) · V_iV_j / (D_ij/\|Δpgdp\|)^λ` | 王梦宇等(2024) 统计与决策 |

完整输出：网络密度/关联度/等级度/效率/小世界、点度/接近/中介中心度、CONCOR 板块、核心-边缘结构、网络图。

**省际地理距离已内置**（30 个省会经纬度 + Haversine），不用自己找距离矩阵。

```bash
python network_analysis.py --index ../data/我的综合指数.csv --year 2023
python network_analysis.py --raw ../data/demo_共同富裕面板.csv --gravity econ --pgdp ../data/demo_人均GDP.csv
```
→ 写论文时直接抄 `0_方法与公式` sheet。

## 四个容易踩的坑（代码里都已经处理）

1. **★ 做「网络密度的时间演变」时，二值化阈值绝不能交给数据自适应。**
   任何「取中位数当阈值、大于则记 1」的做法都**数学上保证 50% 密度** ——
   `--binarize rowmean`（阈值随行平移）和 `--binarize fixed` 不传阈值（阈值随年平移）
   **都会让关系数年年不变、密度恒为 0.5，趋势被永久钉死**。
   → 必须用固定参考阈值：**`--binarize fixed --fixed mean_ratio`（★推荐，复现文献[2]）**，
   或 `--fixed mean`、`--fixed median_all`，或显式数字。
   **`mean_ratio` 是我们从文献[2]表2 反推出的口径**（阈值 = 全样本引力均值×0.58），
   实测 2013/14/15 密度 0.1828/0.2034/0.2195（文献 0.1782/0.2011/0.2345）、
   2013 年核心区 6 省（文献 6 省）。详见 `说明_02` 第三节。
   代码会打印「二值化趋势诊断」并画出 `trend_关系数与网络密度.png`，序列水平时自动报警。

2. **标准化方法会改变障碍度两榜的关系。**
   默认用 `x/max`（文献口径，X 落在 (0,1]，满足传统模型的前提）。
   用 min-max 会产生 X=0，用 x/均值会超过 1，两者都会打乱两榜的反转结构。
   Z-score 直接禁用（负值会让两个模型同时失效）。

3. **变异系数法必须算在原始值上，不能算在标准化值上。**
   min-max 会把每个指标的极差强行拉成 1，各指标 CV 被拉平，
   权重退化成近似等权（我实测过：CV 从 0.87 掉到 0.078）。CV 本身无量纲，直接算原始值。

4. **经济地理距离会除零。**
   两省人均 GDP 接近时 `D/|Δpgdp|` 爆掉。代码用「GDP 差距中位数的 1‰」做相对下限保护。
   论文原文没有这一步。

## 已验证的一致项

用论文报告值反查过实现，**10 项对上**：

| 项目 | 我的实现 | 论文值 |
|---|---|---|
| 网络密度（文献[2] 2013） | 155/870 = 0.1782 | 0.1782 ✅ |
| **复现 2013 密度（`mean_ratio`）** | **0.1828** | 0.1782 ✅ |
| **复现 2014 密度（`mean_ratio`）** | **0.2034** | 0.2011 ✅ |
| **复现 2015 密度（`mean_ratio`）** | **0.2195** | 0.2345 ✅ |
| **复现 2013 核心区数（`mean_ratio`）** | **6 省** | **6 省** ✅ |
| 点度中心度 北京/江苏/内蒙古/新疆 | 96.552 / 98.276 / 27.586 / 10.345 | 完全一致 ✅ |
| 接近中心度 北京 | 29/30 = 96.667 | 96.667 ✅ |
| 网络效率（文献[2] 2020） | 0.6885 | 0.6897 ✅ |
| 新质生产力「生产力要素 59.04% / 创新要素 40.96%」大结构 | 用论文权重可复现 | ✅ |

**3 项对不上，且都能定位原因**（详见 `说明_02` 第四、五、七节）：
- 文献[2] 的网络等级度：论文未给定义，用任何标准公式都无法复现其数列
- 文献[2] 江苏 2021 年接近中心度：该省点出度 = n−1，按公式应为 100，论文给 98.3335
- 文献[2] 2021 年核心区 14 省 / 成员构成：属数据层面差异（demo 为模拟数据），
  换真实数据后会变；如需强行对齐可用 `--core-n 14`
